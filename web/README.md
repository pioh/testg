# Дашборд анализа производительности

Интерактивный веб-дашборд для визуализации и анализа результатов тестирования производительности различных приложений.

## Особенности

- Автоматическое обнаружение последнего прогона тестов
- Интерактивные диаграммы для сравнения различных приложений
- Тепловые карты для анализа зависимостей параллельности и глубины
- Автоматическое обновление данных
- Интерактивная таблица с полными результатами
- Выявление аномалий и интересных паттернов

## Установка

1. Убедитесь, что у вас установлен [Bun](https://bun.sh/) или другой менеджер пакетов JavaScript
2. Клонируйте репозиторий
3. Перейдите в директорию `web`
4. Установите зависимости:

```bash
bun install
```

## Запуск

```bash
bun start
```

или

```bash
bun main.js
```

Сервер будет запущен по адресу [http://localhost:3000](http://localhost:3000)

## Структура проекта

- `main.js` - основной серверный файл, отвечающий за обнаружение последних данных и API
- `public/` - статические файлы
  - `index.html` - основной HTML-файл с разметкой интерфейса
  - `styles.css` - стили для интерфейса
  - `app.js` - клиентский JavaScript для визуализации данных

## Возможности визуализации

- Сравнение максимального RPS между приложениями
- Графики латентности (P99) в зависимости от параллельности
- Сравнение использования CPU и памяти
- Тепловые карты для анализа влияния параллельности и глубины
- Графики масштабируемости для разных метрик
- Полная таблица всех результатов с возможностью фильтрации и сортировки
